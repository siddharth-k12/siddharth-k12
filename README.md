### 🚧 Featured Projects

**🔹 [AI-Powered Job Portal](https://github.com/siddharth-k12/Jobprotal)** — [Live Demo](https://jobprotal-frontend-tptp.onrender.com/)
`React.js` `Node.js` `Express.js` `MongoDB` `FastAPI` `LangChain` `RAG`
Full-stack job portal with 20+ REST endpoints, JWT + RBAC auth with ownership-based access control, Cloudinary-backed multi-resume management, a decoupled Python FastAPI microservice for resume parsing, and a LangChain RAG pipeline with Mistral AI for ATS-style match scoring.

**🔹 [Multi-Vendor Marketplace Backend](https://github.com/siddharth-k12/multi-vendor)**
`Node.js` `Express.js` `MongoDB` `Socket.IO` `JWT` `Cloudinary`
Marketplace backend for Admin/Vendor/Customer workflows — RBAC-driven vendor onboarding, inventory, cart, wishlist, orders, wallet, plus real-time notifications and 1:1 chat via Socket.IO.

**🔹 [PDF RAG Assistant](https://github.com/siddharth-k12/Rag-Project)**
`Python` `LangChain` `Mistral AI` `ChromaDB` `Streamlit`
Upload-a-PDF, ask-natural-language-questions RAG app — PyPDFLoader + RecursiveCharacterTextSplitter for chunking, Mistral embeddings in ChromaDB with MMR retrieval, grounded prompting, tested via both Streamlit and CLI.
